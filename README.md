Student Management API — Spring Boot

A REST API for managing students with Spring Boot, MySQL and Swagger UI.

## Features
- Add, retrieve and delete students
- Count students
- Query students by birth year
- Swagger/OpenAPI documentation
- Controller unit tests

## Architecture
REST Client → Controller → Service → Repository → MySQL

## Stack
Java 17+ · Spring Boot · REST · MySQL · Maven · Swagger/OpenAPI

## Run
Create a MySQL database named `studentdb`, configure `application.properties`, then run `mvn spring-boot:run`.
